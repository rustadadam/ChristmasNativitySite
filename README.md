# Community Creche site

A quick, AI-vibed website to help Jana Keen with her Community Creche (Thursday, December 17, noon to 9:00 PM, Orem, Utah).

- **One page** ([index.html](index.html), [styles.css](styles.css), [app.js](app.js)), styled after the printed flyer ([IMG_3109.png](IMG_3109.png)).
- **Performance sign-ups** in 15-minute slots from noon to 9:00 PM. One person or group per slot, shown by name on the page.
- **Creche pledges**: how many creches people will bring, with the running total shown on the page.
- **Phone numbers stay private.** They are stored in a Google Sheet that only the owner can open ([apps-script/Code.gs](apps-script/Code.gs)).
- **QR code** generated by [tools/make_qr.py](tools/make_qr.py).

**To get it live, follow [SETUP.md](SETUP.md).**
